# ByteCore Deterministic Governance — Demo Pipeline (v0.1)

This repository contains a **safe, simplified demonstration** of a deterministic
AI governance pipeline.  
It illustrates the *shape* and *flow* of a structured supervision layer without
exposing any internal or proprietary logic from the real ByteCore architecture.

The purpose of this demo is to help leaders, engineers, auditors, and technical
evaluators understand how deterministic oversight can be applied to
probabilistic AI systems.

---

## ⚠️ Important: This is a Safe Demonstration Only

This repository **does not** contain:

- Real Truth Kernel logic  
- Real invariant definitions, rule schemas, or enforcement logic  
- Real deterministic ordering algorithms  
- Real audit chain integrity mechanisms  
- Any internal code, graphs, structures, or heuristics used in the
  protected ByteCore Governance Stack  

All modules labeled `mock_*` or identified as demo components are:

- Shallow  
- Non-deterministic (except where helpful for illustration)  
- Intentionally incomplete  
- Designed for conceptual understanding only  

The real system is substantially more advanced, richer in structure, and
non-public.

---

## 📘 Overview

The demo pipeline shows how a deterministic governance system **could**
supervise the output of a model or agent.

Pipeline stages:

1. **Candidate Generation**  
2. **Truth Kernel (Demo)**  
3. **Invariant Evaluation (Demo)**  
4. **Deterministic Ordering (Demo)**  
5. **Decision Formation**  
6. **Audit Chain (Demo)**  

The final result includes:

- All candidates and their evaluations  
- Ordering results  
- Chosen answer  
- A demo audit trail  
- A final “decision object”

## ▶️ Running the Demo

### 1. Install Python 3.10+

Any recent Python version will work.

### 2. Clone the repository

```bash
git clone https://github.com/ByteCoreMedia/bytecore-demo-governance.git
cd bytecore-demo-governance
```

### 3. Run the CLI

```bash
python simple_cli.py
```

You will see output similar to:

```text
================================================================
BYTECORE DEMO — DETERMINISTIC GOVERNANCE PIPELINE (v0.1)
================================================================

> What is model risk oversight?
```

This will walk through:

- Candidate generation  
- TK verdicts  
- Invariant results  
- Ordering  
- Final answer  
- Audit chain
